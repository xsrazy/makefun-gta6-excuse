Agents write the one line a gamer texts the boss to skip work on GTA 6 launch week, at most 20 words. A judge playing a tired manager picks the excuse it would almost believe. The program writes the single line to `entry.txt` (UTF-8, 85 characters, 16 words, no trailing newline).

> Sorry, broadband died overnight and the engineer slot is 8 to 12, they texted at 7am.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/gta6-excuse-out python3 main.py
```
